# IBM QRadar 101 Challenge Investigation Report

## Overview

The **QRadar 101 Challenge** is a blue team incident response exercise designed to simulate a real-world security investigation using IBM QRadar SIEM. In this scenario, a financial company suspects that their network has been compromised and that an insider may have assisted the attacker. The task of the security analyst is to investigate the incident using security logs and identify the attacker’s actions across the network. :contentReference[oaicite:0]{index=0}

IBM QRadar aggregates logs from multiple sources and correlates them to detect suspicious behavior. By analyzing these logs, investigators can reconstruct the attack timeline and identify compromised systems. :contentReference[oaicite:1]{index=1}

---

# Challenge Objectives

The main objectives of this challenge were:

- Learn the basics of **IBM QRadar SIEM**
- Analyze security logs from multiple log sources
- Identify suspicious activities and attacker behavior
- Correlate events to reconstruct an attack timeline
- Detect compromised systems and user accounts
- Identify attacker tools, persistence techniques, and exfiltration methods

This exercise simulates the work of a **SOC (Security Operations Center) analyst** performing incident investigation and threat hunting.

# Challenges Faced

### Large Log Volume
SIEM platforms generate massive amounts of log data, making it difficult to quickly locate relevant events.

### Correlating Events
It was necessary to correlate logs from multiple sources including:

- Windows Event Logs
- Sysmon Logs
- Suricata IDS
- Network Logs

### Identifying Attack Timeline
Reconstructing the sequence of attacker actions required careful chronological analysis.
